Evergreen

Finds end-of-life and deprecated runtimes, packages, and GitHub Actions in your repository. Every finding shows the exact file and line, an authoritative source, a replacement, and migration steps.

  • Deterministic and offlineNo account, no network call, the same result every run.
  • Honest about gapsNo rule for a package? It says no-data, never safe.
  • For people and agentsCLI, local MCP server, GitHub Action with SARIF, and an Agent Skill.

Why Velella

A Velella is a small blue sailor that drifts on the open sea. It carries a sail, reads the wind, and travels in colonies of thousands, each one small, together hard to stop.

That is the idea: small, sharp tools that work together, so your software keeps moving when the wind changes.
