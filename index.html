Ebb

The open almanac of software end-of-life. 752 rules across 25 ecosystems say what is deprecated, unsupported or removed, since when, and what to move to. Every rule cites its source.

  • Evidence, not opinionEach rule names the authoritative source, the date it was read, and who reviewed it.
  • Standard identifiersComponents are named by purl and versions by VERS, so any tool can ask.
  • Offline by defaultThe rules ship inside the package. No account, no network call.
View on GitHub npm
lookup.ts
import { lookupProduct } from "@velella/ebb/lookup";

const node = await lookupProduct("node", "18.20.4");
node.status;   // "end-of-life"
node.deadline; // "2025-04-30"

const req = await lookupProduct("pkg:npm/request", "2.88.2");
req.status;      // "deprecated"
req.replacement; // "Native fetch or a maintained HTTP client"

Why Velella

A Velella is a small blue sailor that drifts on the open sea. It carries a sail, reads the wind, and travels in colonies of thousands, each one small, together hard to stop.

That is the idea: small, sharp tools that work together, so your software keeps moving when the wind changes.
