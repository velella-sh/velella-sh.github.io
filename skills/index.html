Architecture

How Skills Work

Built on the open standard specified by skills.sh and Claude Code plugins.

01

Declarative Markdown

Every skill contains a standard SKILL.md defining precise trigger conditions, inputs, and output formats.

02

Zero-Dependency CLI

Runs offline and locally via ebb check or lookup without mandatory network calls or external tracking.

03

Structured Output

Returns clear, actionable statuses (supported, deprecated, end-of-life) and cited migration sources.
